# Tic Tac Toe Game

A simple two-player Tic Tac Toe game built using **HTML, CSS, and JavaScript**.

## Features

- Two-player gameplay using **O** and **X**.
- Detects the winner when a player gets three marks in a row, column, or diagonal.
- Detects a draw when all boxes are filled and there is no winner.
- **New Game** and **Reset Game** buttons to start again.

## Files

- `index.html` – creates the game page and board.
- `style.css` – styles the game board, boxes, and buttons.
- `program.js` – handles player turns, winning combinations, and game results.

## How to Run

1. Download or clone this repository.
2. Keep all three files in the same folder.
3. Open `index.html` in a web browser.
4. Click the boxes to play.

## Technologies Used

- HTML
- CSS
- JavaScript
